方案 A：CosyVoice（高质量，AutoDL GPU）
CosyVoice 是阿里达摩院的开源 TTS，自然度业界顶级。部署在你 AutoDL 的 4090 机器上（和 ComfyUI 同一台）。

步骤：


1. SSH 到 AutoDL 机器，开一个新的 tmux/screen 窗口（别和 ComfyUI 挤）

2. 克隆仓库 + 装依赖：
   git clone https://github.com/FunAudioLLM/CosyVoice.git
   cd CosyVoice
   pip install -r requirements.txt
   pip install fastapi uvicorn  # 我们用 FastAPI 包一层 HTTP 接口

3. 下载模型（约 1.5GB）：
   python -c "from modelscope import snapshot_download; snapshot_download('iic/CosyVoice-300M-SFT')"
   可选更大模型：iic/CosyVoice-300M-Instruct（支持 zero-shot 克隆音色）

4. 创建一个 FastAPI 封装脚本（保存为 server.py）：

```python
from fastapi import FastAPI
from fastapi.responses import Response
from pydantic import BaseModel
import cosyvoice, torch
from cosyvoice.cli.model import CosyVoiceModel, CosyVoice2Model

app = FastAPI()
model = CosyVoiceModel.from_pretrained('pretrained_models/CosyVoice-300M-SFT')

class TTSReq(BaseModel):
    text: str
    speaker: str = "default"
    emotion: str = "平静"
    mode: str = "s1"

@app.post("/tts")
async def tts(req: TTSReq):
    # emotion 可以传给模型做 zero-shot，也可以简单忽略用默认音色
    output = model.inference_sft(req.text, req.speaker)
    wav_bytes = output['tts_speech'].cpu().numpy().tobytes()
    return Response(content=wav_bytes, media_type="audio/wav")

@app.get("/voices")
async def voices():
    return ["default", "male1", "female1", "male2", "female2"]

```

5. 启动服务（AutoDL 上要开端口转发 50000）：
   ```
   uvicorn server:app --host 0.0.0.0 --port 50000
   ```

6. 拿到公网地址（和 ComfyUI 的 AutoDL 代理地址类似），填到本地 `.env`：
   ```
   TTS_BASE_URL=https://你 的-tts-公网地址:50000
   ```

7. **不用重启后端**——`tts.py` 的 `get_tts_provider()` 每次调用时会重新读取配置。下次配音就自动切到 CosyVoice 了。
方案 B：edge-tts（当前已可用，零配置）
不用管——我已经帮你装好了，代码也改好了。当前 .env 里 TTS_BASE_URL=http://REPLACE_ME:50000 是占位符，get_tts_provider() 检测到"REPLACE_ME"就自动走 edge-tts。

但 edge-tts 生成的是 .mp3，而 CosyVoice 是 .wav。合成时 ffmpeg 都能处理，不影响。

情绪映射（已完成）
你之前提到"配音时情绪应该有波动"——已经实现了：

分镜表解析时自动抽情绪（如 林渊：（紧张）师父人呢？）

emotion 字段写入数据库

二、合成（Compose）完整配置指南
合成完全不走 ComfyUI，就一个依赖：ffmpeg。当前本地没装，是第一步要做的。

合成流程图



已审核通过的镜头视频 ──┐
                       ├─→ ffmpeg ──→ 每段混流（视频+该段配音+静音补空）──→ concat 拼接 ──→ 字幕烧录 ──→ BGM 混音 ──→ 最终 MP4
该镜头的所有对白音频 ──┘
配置步骤



===== 第 1 步：安装 ffmpeg（必须）=====

Windows 本地开发：
  a. 去 https://www.gyan.dev/ffmpeg/builds/ 下载 ffmpeg-release-essentials.zip
  b. 解压到 C:\ffmpeg\
  c. 把 C:\ffmpeg\bin 加到系统 PATH
  d. 开新终端，ffmpeg -version 能输出版本号就 OK

AutoDL GPU 机器（如果合成也想放云端）：
  apt update && apt install -y ffmpeg

===== 第 2 步：配置（可选）=====

.env 里目前没有合成专用配置。compose.py 里硬编码了：

- 输出目录：./data/media/exports/

- 视频编码：libx264 crf=20 preset=fast

- 帧率：16fps（和 Wan2.1 视频生成帧率一致）

- 音频编码：aac 24kHz

这些默认值够用，不用改。

如果你有 BGM 想合成时自动混，之后可以加个 BGM_PATH 配置，但当前接口是手动传 bgm_path 的。

===== 第 3 步：合成步骤 =====

1. 确保每个要合成的镜头：
   ✅ 有审核通过的视频候选（status=通过）
   ✅ 该镜头下所有对白都配完音（audio_url 不为空）
   ✅ 没对白的镜头自动补静音

2. 在"合成"页点"合成"，会调 /api/scripts/{id}/compose
   后端走 compose_episode Celery 任务 → export_episode() → ffmpeg subprocess

3. 合成进度条会显示在合成页（和视频生成/配音一样走 usePollTask）

4. 完成后下载 MP4，路径：data/media/exports/ep_xxx.mp4
合成需要我帮你改的地方
当前代码里 ffmpeg 找不到的话会直接报错。你先装一下 ffmpeg（上面第1步），装完后合成就能跑。

另外还有几个可以改进的点，如果你需要我可以后续加：

音画对齐：当前配音时长和视频时长可能不匹配，ffmpeg concat 时没有精确对齐（简单拼接，静音补空），需要更精细的时间轴控制

BGM 上传：当前只支持后端传文件路径，没有前端上传 BGM 的入口

字幕样式：当前用默认白色字幕，可以加字体/大小/位置配置
